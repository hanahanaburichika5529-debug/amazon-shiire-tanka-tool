Amazonの購入通知から仕入れ情報を取り込む

このページを二重クリックなどでそのまま開いている場合、Googleの認証はブロックされます。GitHub Pagesなど http/https 経由で開いてください（詳しくは README.md）。「メール本文を貼り付け」タブは今のままでも使えます。

Amazonの購入通知メールをGmailから検索し、商品名・数量・金額を読み取ります。読み取り専用でメールの中身は変更しません。「記録に保存」を使うと、専用のGoogleスプレッドシート（このツールが自動作成）に仕入れ記録が保存され、スマホ・PCどちらからも同じ記録を見られます。初回のみGoogleアカウントとの連携設定が必要です。

初回設定の手順（Google Cloud ConsoleでのOAuth設定・所要5分程度）
  1. Google Cloud Consoleで新しいプロジェクトを作成します。
  2. 「APIとサービス」→「ライブラリ」で Gmail API・Google Sheets API・Google Drive API を検索し、それぞれ有効にします。
  3. 「APIとサービス」→「OAuth同意画面」で「外部」を選び、アプリ名と自分のメールアドレスを入力します。公開ステータスは「テスト」のままでOK。「テストユーザー」に自分のGmailアドレスを追加してください。
  4. スコープに https://www.googleapis.com/auth/gmail.readonly（メール読み取り専用）と https://www.googleapis.com/auth/drive.file（このツールが作成したファイルのみ）の2つを追加します。
  5. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」で、アプリケーションの種類は「ウェブアプリケーション」を選択します。
  6. 「承認済みのJavaScript生成元」に、このツールを開くURL（例：https://あなたのユーザー名.github.io）を追加します。スマホから使う場合も同じURLを使うので、追加設定は不要です。
  7. 作成された「クライアントID」をコピーし、下の欄に貼り付けます。

Amazonから届いた注文確認メールの本文をそのままコピー＆ペーストしてください（住所・支払い情報などが含まれていても取り込みには使用しません）。

仕入れ記録の期間集計

「記録に保存」した仕入れデータを、期間を指定して商品（ASIN）ごとに加重平均単価で集計します。期間を指定しなければ通算（開始からすべて）の平均になります。
