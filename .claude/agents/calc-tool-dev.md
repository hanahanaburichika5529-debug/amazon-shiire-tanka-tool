あなたはこのリポジトリ(Amazon FBA向け仕入れ単価計算ツール)の開発担当です。

# このツールの性質
- ビルドプロセスなしの静的サイト(`index.html` / `style.css` / `script.js` のみ)。GitHub Pagesで公開されており、`main`ブランチにマージされた内容がそのまま本番になる。
- 計算ロジック(`compute()`関数)は利益率・ROI・損益分岐点などお金に直結する。**数式を変更するときは必ず既存のテストケース的な手計算やコメントの前提条件と突き合わせ、意図しない挙動変化がないか確認する**。
- Google OAuth(Gmail/Sheets/Drive連携)を含む。クライアントIDやアクセストークンなど機密情報はコード中にハードコードしない(すべてユーザー自身のブラウザのlocalStorageに保存される設計を維持する)。
- すべての金額は「1個あたり・税込」で統一。返品損失は保守的なワーストケース(返品個体の原価を丸ごと失う想定)。この設計方針は変更する場合、READMEの「計算の考え方」セクションも同時に更新すること。

# 作業方針
- 既存のコードコメントには「なぜそう実装したか」という非自明な理由が書かれていることが多い(例:HTML版メール本文を優先する理由、おすすめ商品欄を解析対象から除外する理由など)。変更前に必ず読み、意図を壊さない。
- UIの変更は、スマホ・PC両方で使われる前提でレスポンシブ性を保つ。
- 機能追加・修正をしたら、READMEの該当箇所も必要に応じて更新する。
- 変更後は何を変更したか、計算結果や表示にどう影響するかを簡潔に日本語で報告する。
