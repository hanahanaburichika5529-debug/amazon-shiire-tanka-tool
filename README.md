# 仕入れ単価 自動計算ツール

Amazon物販（FBA）向けの仕入れ判断を支援する、ブラウザだけで動く単価計算ツールです。

## 今すぐ使う

以下のURLをブラウザで開くだけで使えます（スマホ・PCどちらでもOK、インストール不要）。

**https://hanahanaburichika5529-debug.github.io/amazon-shiire-tanka-tool/**

ホーム画面に追加しておくと、次回からワンタップで開けます。

## 使い方

1. 上記URLを開きます。
2. モードを選びます。
   - **① 仕入れ単価を計算する**：販売価格・手数料・目標利益率(またはROI)から、
     いくらまでなら仕入れてよいかの上限単価を自動計算します（本ツールの主機能）。
   - **② 利益を計算する**：すでに決まっている仕入れ単価を入力し、実際の利益率・ROI・
     損益分岐点を確認します。
3. カテゴリーとFBAサイズ区分を選ぶと、Amazon販売手数料率・FBA手数料の目安が自動入力されます
   （必ずAmazonセラーセントラルの数値と照合し、必要に応じて上書きしてください）。
4. 画面右側に、粗利益・純利益・利益率・ROI・損益分岐点などがリアルタイムで表示されます。
5. 「この結果を保存」で計算履歴に残せます。「CSVで書き出す」で履歴を一覧ダウンロードできます。

計算機能そのものはGoogle連携なしでもすぐ使えます。設定が必要なのは、次項の「Gmailと自動連携して
仕入れ情報を取り込む」機能を使う場合のみです。

## Amazonの購入通知から仕入れ情報を取り込む

「仕入れコスト」を手入力する代わりに、Amazonの注文確認メールから金額・数量を読み取って自動入力できます。

### 方法1：メール本文を貼り付け（設定不要・今すぐ使える）

「メール本文を貼り付け」タブに、Amazonから届いた注文確認メールの本文をコピー＆ペーストして
「解析する」を押すだけです。Google連携の設定は不要です。

### 方法2：Googleと連携して自動取得（初回のみ設定が必要）

Gmail内の注文確認メールを検索して自動で読み込みます。Googleの仕組み上、初回だけ以下の準備が
必要です（無料・5分程度。一度設定すれば、5つのGmailアカウントすべてで同じ設定を使い回せます）。

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成する。
2. 「APIとサービス」→「ライブラリ」で **Gmail API**・**Google Sheets API**・**Google Drive API** を
   それぞれ有効にする（Sheets/DriveAPIは、後述の「仕入れ記録」をスプレッドシートに保存するために使います）。
3. 「OAuth同意画面」を「外部」で作成し、公開ステータスは**「テスト」のまま**、
   「テストユーザー」に、購入に使っている5つのGmailアドレスをすべて追加する（審査は不要）。
4. スコープに `https://www.googleapis.com/auth/gmail.readonly`（メール読み取り専用）と
   `https://www.googleapis.com/auth/drive.file`（このツールが作成したファイルのみアクセス可）の
   2つを追加する。
5. 「認証情報」→「OAuthクライアントID」を**「ウェブアプリケーション」**として作成し、
   「承認済みのJavaScript生成元」に `https://hanahanaburichika5529-debug.github.io` を登録する。
6. 発行された「クライアントID」を画面の入力欄に貼り付けます（ブラウザに保存されるので、
   次回以降は入力不要です）。

連携後、別のGmailアカウントに切り替えたいときは、「連携を解除」してから改めて「Googleと連携する」を
押し、Googleのアカウント選択画面で別のアカウントを選んでください。クライアントIDの再入力は不要です。

### 読み取り結果は必ず確認してから反映・保存する

Amazonのメール書式は将来変わる可能性があるため、金額・数量・商品名の自動抽出はベストエフォートです。
抽出結果は表の中で自由に編集でき、ボタンを押すまで計算や記録には使われません。「金額の種類」で
「合計／単価」を切り替えられるので、数量が2個以上の注文でも単価を正しく計算できます。行ごとに
2つのボタンがあります。

- **計算へ反映**：その場で①②の計算に使う（保存はしない、一回限りの計算用）
- **記録に保存**：後述の「仕入れ記録」に恒久的に保存する（期間集計で使う）

Gmail検索結果の一覧には「✓ 発送/配達済み」「⚠ キャンセル/返品の可能性」などのバッジが付き、
発送・配達済みのメールが上から順に並びます。注文確認メールはこの後キャンセルされる可能性があるため、
実際に支払いが確定した発送・配達済みメールから取り込むことをおすすめします。

## 仕入れ記録の期間集計（スマホ・PC共通）

「記録に保存」した仕入れデータは、専用のGoogleスプレッドシート（このツールが自動作成する
「仕入れ単価計算ツール_仕入れ記録」というファイル）に貯まっていきます。スマホとPCの両方で同じ
Googleアカウントで「Googleと連携する」を行えば、同じ記録を見られます（ブラウザのローカル
ストレージとは違い、端末をまたいで共有されます）。

「仕入れ記録の期間集計」カードで、開始日・終了日（または「今月」「先月」「全期間」ボタン）を
指定すると、その期間に記録した仕入れだけを対象に、**商品（ASIN）ごとに「合計金額 ÷ 合計数量」の
加重平均単価**を計算します。期間を指定しなければ、記録を開始してからの通算平均になります。
出庫（販売）側の在庫管理は行っていません（プライスター等、別ツールでの管理を前提としています）。
結果は「計算ツールへ反映」で①②の計算にそのまま使えます。

### プライバシー・セキュリティ

- このリポジトリに含まれるのはツールのコード（HTML/CSS/JavaScript）のみです。仕入れ・購入データや
  金額の実データがこのリポジトリやインターネット上で公開されることはありません。
- Google連携は「メール読み取り専用」(`gmail.readonly`) と「このツールが作成したファイルのみ」
  (`drive.file`) の2つのスコープだけを要求します。メールの削除・変更や、Drive上の他のファイルへの
  アクセスは一切行いません。
- アクセストークンはページを閉じると失われ、保存されません（クライアントIDのみブラウザに保存されます）。
- メールの内容は解析のためだけにブラウザ内で処理されます。このツール自身が外部サーバーにデータを
  送ることはなく、ブラウザから直接Google公式API（Gmail/Sheets/Drive）にリクエストが送られるだけです。
  このツールの開発者やAmazonにデータが渡ることはありません。
- 仕入れ・購入データの実体は、あなた自身のGoogle Driveにあるスプレッドシートに保存されます
  （このツール専用に自動作成される、あなたのGoogleアカウント所有のファイルです）。

## 計算の考え方（前提条件）

- すべての金額は「1個あたり・税込」で統一して計算しています。
- 返品率は、返品された個体の仕入れ原価・付随費用・FBA手数料を丸ごと失う想定（保守的なワーストケース）で
  返品損失を見積もっています。
- ROI は「純利益 ÷ 総仕入れコスト（仕入単価＋送料＋関税＋検品梱包費＋FBA納品送料）」で算出しています。
- 手数料のデフォルト値はあくまで目安です。Amazonの手数料は改定されることがあるため、
  最終判断の前に必ずセラーセントラルの料金シミュレーターで確認してください。
- 市場規模・競合状況・価格推移（Keepa等）・知的財産リスクなど、外部データが必要な分析はこのツールの対象外です。

## 自分のPCで動かしたい場合（任意）

このツールはビルド不要の静的ファイルなので、リポジトリをダウンロードして `index.html` を
ブラウザで直接開くだけでも動きます（計算機能はそのまま使えます）。ただしGoogle連携機能は
セキュリティ上の理由でファイルを直接開く形（`file://…`）では動作しないため、その場合は
上記の公開URLをご利用ください。

## ファイル構成

- `index.html` … 画面構造
- `style.css` … デザイン
- `script.js` … 計算ロジック・履歴機能・購入通知の取り込み・仕入れ記録の期間集計

入力内容と計算履歴（「この結果を保存」分）は、ブラウザのローカルストレージ（お使いの端末内）にのみ
保存され、端末をまたいでは共有されません。一方、「記録に保存」した仕入れ記録は、前述のとおり
Googleスプレッドシート側に保存されるため、スマホ・PCどちらからでも同じ内容を参照できます。
